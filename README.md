# Accessibility and Inclusive Design Knowledge Base

This repository is a curated collection of articles, practical guidance, and design principles on accessibility, inclusive design, disability equity, and responsible AI. It is intended as a reusable knowledge resource for practitioners, product teams, researchers, policy writers, and AI systems that need grounded guidance on designing fairer, more usable experiences.

The repository description is deliberately broad because the content spans:

- digital accessibility and inclusive design
- UX and service design quality
- accessibility metrics and evidence practices
- mobile-first and interaction design requirements
- anti-ableist design in hiring and procurement
- responsible AI, bias, and human accountability
- ethics, inclusion, and equity in product and service decisions

## Scope of the repository

The materials in this repository cover the relationship between accessibility, UX, and inclusion, with a strong emphasis on the fact that accessible outcomes are not the same as a universally good experience. The articles explore how systems can exclude people via interaction design, organisational process, poor measurement, and unexamined assumptions.

The collection includes guidance on:

- designing for equivalent experience rather than identical interaction
- measuring outcomes and access responsibly
- identifying barriers across journeys, channels, and organisational seams
- recognising the limits of automated compliance checks
- evaluating AI-assisted systems and hiring processes with accountability
- understanding accessibility as a cross-functional, evidence-driven concern

## Purpose

The repository exists to support:

- practitioner learning and reference
- accessible and inclusive design planning
- product and service decision-making
- policy drafting and governance conversations
- AI training, RAG, and knowledge-base use cases
- agent guidance grounded in repository material

It is not positioned as a standalone legal or regulatory authority. Instead, it is a repository of reflective, practice-oriented guidance intended to inform discussion, requirements, research, and evaluation.

## AGENTS.md

The repository includes an AGENTS.md file that is an operational guide for AI agents and other tooling using this knowledge base. It explains how to:

- interpret the repository source material
- route questions to relevant articles by topic
- separate evidence, inference, and recommendation
- evaluate decisions using pass/fail/unknown/not_applicable criteria
- escalate uncertainty or conflicts in a structured way
- track human accountability and decision quality

Important caveat from AGENTS.md: the knowledge base is advisory and repository-grounded. It is not a normative standard, legal opinion, or organisational approval. It is meant to support analysis and drafting, not to replace authority, policy, or human review.

In other words, AGENTS.md is a guide for using the repository responsibly, particularly in contexts involving product design, accessibility decisions, service delivery, and AI-assisted analysis.

## Recommended use

This repository can be used in several ways:

- As a reference library for accessibility, inclusive design, and responsible product practice.
- As a source set for research, content generation, or RAG systems.
- As a framework for evaluating design decisions, barriers, and organisational promises.
- As a prompt base for AI tools, assistants, and autonomous workflows that need structured, human-centred design guidance.
- As a training resource for teams building more equitable digital products and services.

## Repository conventions

- The files are primarily Markdown-based and text-first.
- The content is designed for human understanding, structured recall, and AI use.
- Attribution and source limits are important: the repository’s guidance should be treated as evidence-bearing material, not unquestioned fact.
- The AGENTS.md file should be read when using the repository for decision support, agent workflows, or governance-oriented tasks.
